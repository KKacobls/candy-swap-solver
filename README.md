# KK Candy Solver — 6 × 7 糖果交換計算器

這是一個純前端 JavaScript 三消解題器，適用於 6 欄 × 7 排的糖果遊戲截圖。

## 網站

https://kkacobls.github.io/candy-swap-solver/

> 若網頁尚未公開：在本儲存庫的 **Settings → Pages → Build and deployment** 中，選擇 **Deploy from a branch**，Branch 設為 **main** / **/(root)**，儲存即可。

## 使用方法

1. 開啟網站，上傳、拖放或貼上遊戲截圖。
2. 網站自動定位 6 × 7 棋盤並辨識糖果顏色。
3. 檢查辨識結果。如有錯誤，可點選格子修改顏色，也可以手動框選棋盤範圍。
4. 查看全部有效相鄰交換，依紅、黃、紫、粉紅或總消除數排序。
5. 點選結果列，棋盤會用箭頭標出交換位置，並標記可立即消除的糖果。
6. 支援複製 ASCII 棋盤、匯出 CSV。

## 計算規則（依遊戲內攻略圖片）

- 枚舉 6 欄 × 7 排棋盤的 71 組水平與垂直相鄰位置（特殊糖果的拖動方向會影響結果）。
- 一般糖果：連續 3 顆同色會消除；4 顆同色消除可生成「糖果罐」；5 顆以上同色可生成「龍鬚酥」。
- **糖果罐**（J）：拖動後按新位置中心的 **3×3 九宮格**估算當次清除。
- **龍鬚酥**（D）：拖動後按新位置所在的**整排＋整欄十字區域**估算當次清除（中心只計算一次）。
- 各色欄位顯示被清除區域內紅、黃、紫、粉紅糖果數，特殊格另標記。
- 僅計算第一輪普通消除或單次特殊主效果，不疊加額外普通連線、不推測二次特殊觸發，也不模擬掉落、補糖、連鎖。
- 攻略未說明**特殊糖果彼此交換**的結果，因此暫不列入排名；效果位置以拖動後落點為中心，是依攻略圖片作的建模假設，若與遊戲不同請以遊戲實測為準。
- 對於截圖辨識錯誤，可以點格子改成紅／黃／紫／粉／糖果罐／龍鬚酥／未知。
- 一切分析在瀏覽器本機執行，不上傳圖片到伺服器。
